Firmenbriefing in Microsoft 365 Copilot: zwei Agenten mit Skills

Agent Builder, keine Flows, kein SharePoint. Agent 1 erstellt ohne Prüfung. Agent 2 prüft nur, wenn der Nutzer es wünscht. Übergabe über eine Excel-Datei.
Nutzer · Schritt 1
„Briefing zu [Firma], Fokus: [Thema], Gesprächspartner: [Name]“
oder „Nur Portfolio zu [Firma]“
Nutzer · Schritt 2, optional
lädt briefing-daten.xlsx hoch: „prüfen“
oder „nur Portfolio prüfen“, „nur A-Fakten prüfen“

Instructions ≤ 8.000 Zeichen: Auftragswahl, Reihenfolge der Skills, Quellenregeln kurz, Hinweis „ungeprüft“.

Warum so: Skills sind im Agent Builder allgemein verfügbar und führen Python-Skripte in einer Sandbox aus, deshalb rendert ein Skript die HTML statt des Modells. Ein Agent kann keinen anderen aufrufen und Skills sind nicht zwischen Agenten teilbar, deshalb startet der Nutzer die Prüfung selbst und Skill 8 liegt als Kopie in beiden Agenten. HTML ist als Chat-Upload nicht dokumentiert, Excel schon, deshalb läuft die Übergabe über Excel.
Pflege: Instructions und Skillordner liegen im Repo, ein Build-Skript packt die ZIP-Dateien und hält die Kopien gleich.
