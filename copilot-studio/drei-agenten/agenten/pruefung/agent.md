# Agent „Firmenbriefing Prüfung“: Einstellungen

| Feld | Wert |
|---|---|
| Name | Firmenbriefing Prüfung |
| Beschreibung | Prüft eine Briefing-Excel gegen ihre Quellen, korrigiert belegte Abweichungen, vertieft Lücken und gewünschte Themen und liefert briefing-daten-geprueft.xlsx. |
| Instructions | Inhalt von pruefung-instructions.md vollständig einfügen |
| Websuche | an, „alle Websites durchsuchen“ |
| Code Interpreter | an (im Agent Builder immer an) |
| Modell | Mandantenstandard |
